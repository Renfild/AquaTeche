# Роадмап игрока — AquaTech

Короткий путь «что делать дальше». Подробности званий — в [HORIZON_ROUTE.md](HORIZON_ROUTE.md).

## Три трека (не путать)

| Трек | Где | Зачем |
|------|-----|--------|
| **Сюжет / сборка** | Книга **FTB Quests** | Главы Acts I–IV + IU как тех-ядро |
| **Контракты** | **F4 → Квесты** | Этапы плот→IU с пачками ресурсов и XP |
| **Горизонт** | `/aquatech horizon`, daily, season | Звания Матрос→Легенда, права, сезон |
| **Мастерские** | FTB → группа **Мастерские** | **Industrial Upgrade (ядро)**; AE2, Botania+, DE, Avaritia — позже |

Спавн: **личный плот 4×4** (SkyblockBuilder) — при первом входе плот создаётся сам (или `/skyblock create <имя>`). Глубина/давление от моря Y190. Строить можно **только на своём острове** (IslandGuard). Домой: `/skyblock home`. Варпы casesmod: только spawn/shop.

## Этапы сборки (иди по порядку)

| Этап | Фокус | FTB ориентир | Контракты / кейсы |
|------|--------|--------------|-------------------|
| **1 · Плот** | 4×4 дуб, еда, расширение палубы | Act I + старт | Primitive Crate |
| **2 · Улов → IU** | удочки AquaTech → медь/олово/latex IU | Act II + **Мастерская IU I–II** | медь IU, латекс |
| **3 · Примитив–Пар** | hammer, пластины, паровые машины | **Мастерская IU II–III** | Steam Crate / кит пар |
| **4 · Электрика** | Machine Block, BatBox, кабели EF | **Мастерская IU III–IV** | Electric Crate |
| **5 · Завод** | PowerUtils EF→FE + AE2/Botania/DE (**без** TP/полёта/infinity) | IU V + поздние мастерские | компоненты, не готовые машины |

## Что открывать руками

1. **FTB Quests → Мастерские → Industrial Upgrade** — основной тех-путь.
2. **FTB spine** — сюжет океана (линейный режим).
3. **F4 → Квесты / Кейсы / Киты** — ускорители стадии (не шорткат завода).
4. **`/aquatech daily`** / **`horizon`** / **`season`**.

## Награды

- Кейсы: Primitive / Steam / Electric — сырьё и ускорители рыбалки, не полный электро-завод.
- FTB: гайдовые шаги + XP; OP-награды вырезаны.
- Рыбалка: early loot = медь/олово/latex IU + дерево для плота.

## Баланс воды

- Нет craft телепортов IU/DE/AE2 spatial/quantum, джетпаков, creative, Neutron Collector, Infinity-катализаторов, QuantumGenerators.
- Alfheim (Botania World Seed) — **легальное** отдельное измерение.
- Aquaculture снят (рыбалка только aquatech Tide Tension).
- Карьеры отключены (`disable_quarries.zs`).
- Глубина ниже Y140 — давление / DeepBuildGuard.
