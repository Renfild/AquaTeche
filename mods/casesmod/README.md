# CasesMod — Кейсы, Киты, Варпы, Квесты, Привилегии (Forge 1.20.1)

Кастомное меню сервера в стиле **liquid glass** (аналог Apple Liquid Glass /
visionOS): полупрозрачные скруглённые панели с бликами, стеклянная шапка
профиля (скин, ник, баланс). Разделы: **Кейсы**, **Киты**, **Варпы**,
**Квесты**, **Привилегии**.

Кейсы открываются **прямо в меню за внутриигровую валюту** — никаких
физических ключей. Приз сразу падает в инвентарь (или на землю, если
инвентарь полон), а команды и GUI используют одну и ту же систему —
что выдано командой, то и видно/крутится в меню, и наоборот.

## Сборка

1. Установите Forge MDK для 1.20.1 (версия `47.3.0` уже прописана в `build.gradle`).
2. `./gradlew build` — соберёт `.jar` в `build/libs/`.
3. Для теста: `./gradlew runServer` / `./gradlew runClient`.

## Открытие меню игроком

- Команда `/menu`
- Или предмет-открыватель: выдайте его командой `/casesmod givemenu <игрок>`,
  игрок открывает меню правым кликом по предмету.

При открытии меню сервер сразу передаёт клиенту актуальный баланс валюты —
он отображается в шапке профиля и в разделе кейсов.

## Все команды

| Команда | Доступ | Что делает |
|---|---|---|
| `/menu` | все | Открыть главное меню |
| `/casesmod addbalance <игрок> <сумма>` | OP | Начислить валюту игроку (например, после доната через веб-магазин) |
| `/casesmod setbalance <игрок> <сумма>` | OP | Установить точный баланс |
| `/casesmod balance <игрок>` | OP | Посмотреть баланс игрока |
| `/casesmod opencase <игрок> <caseId>` | OP | Мгновенно открыть кейс игроку **бесплатно** (без списания валюты) — для админ-бонусов, ивентов, наград за голосование |
| `/casesmod givekit <игрок> <kitId>` | OP | Выдать кит, игнорируя кулдаун |
| `/casesmod givemenu <игрок>` | OP | Выдать предмет для открытия меню по ПКМ |
| `/casesmod setwarp <id>` / `delwarp <id>` | OP | Управление точками телепортации |
| `/casesmod reload` | OP | Перечитать все JSON-конфиги без рестарта сервера |

`caseId` и `kitId` подсказываются автодополнением (Tab).

### Интеграция с донат-магазином

Начисление валюты после оплаты — одна команда из консоли/веб-панели:
```
casesmod addbalance %player% 500
```
Игрок сам тратит валюту на любой кейс через `/menu` → Кейсы. Никакой
дополнительной синхронизации не требуется — баланс общий для команд и GUI.

## Кастомизация кейсов

`config/casesmod/cases/<любое_имя>.json`:

```json
{
  "id": "donate_case",
  "displayName": "§6§lДонат-кейс",
  "price": 500,
  "iconItemId": "minecraft:ender_chest",
  "items": [
    { "itemId": "minecraft:diamond_block", "count": 1, "weight": 30, "rarity": "RARE",      "displayName": "§9Блок алмаза" },
    { "itemId": "minecraft:elytra",        "count": 1, "weight": 5,  "rarity": "LEGENDARY", "displayName": "§6§lЭлитры" },
    { "itemId": "minecraft:name_tag",      "count": 1, "weight": 5,  "rarity": "LEGENDARY", "displayName": "§6VIP на 7 дней",
      "command": "lp user %player% parent addtemp vip 7d" }
  ]
}
```

- `price` — стоимость открытия в валюте мода. `0` = открывается бесплатно.
- `pityThreshold` / `pityRarity` — гарантия: после стольких открытий подряд без приза нужной
  редкости — следующее её гарантирует. `0` = pity отключена (по умолчанию).
- `availableFrom` / `availableUntil` — окно доступности в формате `"yyyy-MM-dd"`, пусто = без
  ограничения с этой стороны. Кейс вне окна виден, но не открывается.
- `weight` — вес выпадения приза (не проценты, соотносится с суммой весов всех призов кейса) — чем больше пунктов в `items`, тем разнообразнее призы, никаких ограничений на количество вариантов нет.
- `rarity` — `COMMON / UNCOMMON / RARE / EPIC / LEGENDARY` — влияет на цвет подсветки в рулетке, конфетти и звук при получении.
- `command` — необязательная консольная команда при выигрыше (выдача рангов и т.д.), поддерживает `%player%`.

По умолчанию при первом запуске создаются 3 примера: `common_case` (100 валюты), `donate_case` (500 валюты), `free_case` (бесплатно).

## Кастомизация китов / варпов / квестов

Без изменений: `config/casesmod/kits.json`, `warps.json`, `quests.json` — форматы
описаны в комментариях внутри классов `data/KitDefinition.java`, `WarpDefinition.java`,
`QuestDefinition.java`. Прогресс квестов (`MINE_BLOCK`, `KILL_MOB`, `COLLECT_ITEM`)
отслеживается автоматически через `event/QuestEventHandler.java`.

## UX-концепт: Liquid Glass

- **`client/gui/widget/GlassUI.java`** — примитивы стиля: скруглённые панели
  (`fillRoundedRect` — честная пиксель-точная окружность по строкам, без текстур),
  стеклянные карточки с тенью/бликом/светящейся рамкой (`drawGlassPanel`).
- **`CustomButton`** — кнопки как стеклянные скруглённые чипы с акцентной
  светящейся рамкой при наведении и мягкой анимацией приближения.
- **Главное меню** — статичный (без движущихся полос) тёмно-синий фон с двумя
  мягкими "размытыми" цветовыми пятнами по углам (аппроксимация блюра через
  наложенные полупрозрачные прямоугольники с падающей альфой) и стеклянная
  шапка профиля: реальная иконка головы игрока (текстура скина через
  `PLAYER_HEAD` + NBT `SkullOwner`), ник, статус "В сети", баланс валюты в
  отдельной "таблетке" справа.
- Палитра: холодные аква/бирюзовые акценты (`#5CE1FF`) на тёмно-синей базе,
  разные акцентные цвета на кнопку раздела (кейсы — бирюза, киты — зелёный,
  варпы — синий, квесты — янтарный, привилегии — золото).

## Анимация открытия кейса

Без изменений с прошлой итерации: рулетка в стиле CS:GO с азартной кривой
торможения, подсветкой редкости по всей ленте, эффектом смаза, тряской экрана
и конфетти для EPIC/LEGENDARY, кнопкой пропуска — **плюс теперь кнопка
"← К кейсам"**, которая после завершения анимации возвращает в список кейсов
вместо простого закрытия по ESC.

## Структура проекта

```
src/main/java/com/casesmod/
  CasesMod.java                 — точка входа
  item/                         — предмет-открыватель меню, креатив-вкладка
  data/                         — кейсы/киты/варпы/квесты/валюта (JSON-конфиги)
  network/                      — пакеты клиент↔сервер (в т.ч. синхронизация баланса)
  client/                       — ClientBalanceState, обработчик пакетов
  client/gui/                   — экраны меню + анимация открытия кейса
  client/gui/widget/            — CustomButton, GlassUI (liquid glass примитивы)
  server/commands/               — команды /menu и /casesmod ...
```

## Что нового в этой итерации

- **Собственные звуки** (не ванильные) — `assets/casesmod/sounds/*.ogg`, синтезированы процедурно
  (синусоиды + гармоники + огибающая ADSR через Python/numpy, не позаимствованы из чужих источников):
  тик ленты, нарастающий "свист" перед остановкой, и пять разных мелодий получения приза —
  от простого "дзынь" для обычных до полноценной фанфары с арпеджио и сверкающими обертонами
  для LEGENDARY. Регистрируются как настоящие `SoundEvent` (`item/ModSounds.java`), можно заменить
  файлы на свои — главное сохранить те же имена в `assets/casesmod/sounds/`.
- **Процедурные текстуры** (`assets/casesmod/textures/gui/`, сгенерированы через PIL/numpy):
  мягкое радиальное свечение позади выигрышного предмета (тонируется в цвет редкости), блёстки
  вместо плоских прямоугольников в конфетти, тонкий шумовой грейн поверх фона меню — премиальная
  "материальность" вместо чисто плоских градиентов.
- **Pity-система** (гарантия редкого приза) — поле `pityThreshold` в конфиге кейса: после N открытий
  подряд без приза редкости `pityRarity` или выше, следующее открытие его гарантирует. Прогресс
  сохраняется на диск (`data/PityManager.java`, `config/casesmod/pity.json`) и виден в интерфейсе
  под каждым кейсом ("3/15 до EPIC").
- **Сезонные/ивентовые кейсы** — поля `availableFrom`/`availableUntil` (даты `yyyy-MM-dd`). Кейс вне
  окна виден в меню, но затемнён и заблокирован для открытия с пометкой "🔒 Недоступен" — сервер
  проверяет доступность и при клике, так что клиентскую проверку обойти нельзя.
- **Важное исправление сетевой архитектуры**: раньше `CasesScreen` и лента кейс-опенинга читали
  список кейсов напрямую из серверного `CaseManager` — это работало только в одиночной игре
  (интегрированный сервер в том же процессе), но было бы **пустым на настоящем выделенном сервере**,
  где клиент — отдельный процесс без доступа к файлам сервера. Теперь список кейсов (с ценами, пулом
  призов, шансами, pity-прогрессом и доступностью) передаётся по сети через `CaseListSyncS2CPacket`
  при открытии меню и при `/casesmod reload` — единственный источник истины на клиенте это то, что
  прислал сервер.

- **Лента последних выигрышей** (`data/RecentWinsManager.java`) — последние 20 открытий
  кейсов на сервере (в памяти, сбрасывается при рестарте — это просто атмосфера, не аудит).
  Рассылается всем игрокам онлайн через `RecentWinsSyncS2CPacket` при каждом новом выигрыше
  (и как снимок — новому игроку при входе на сервер, `event/PlayerSyncHandler.java`).
  Отображается стеклянной панелью в правой части главного меню (только если ширина окна
  ≥ 900px, чтобы не перекрывать кнопки на маленьких окнах) — ник, приз, цветная точка редкости.
- **Иконки предметов** в кнопках Китов, Варпов и Квестов (берутся из `iconItemId`/`items[].itemId` конфига) — раньше иконка была только у кейсов.
- **Fade + slide анимация появления** — кнопки всех экранов меню проявляются каскадом (снизу вверх, с нарастанием прозрачности), а не выскакивают все разом. Задержка между кнопками задаётся через `appearDelayMs` в конструкторе `CustomButton`.
- **Реальная проверка прав для китов** (`data/KitDefinition.java` → поле `permission`) через `util/PermissionsHelper.java`:
  1. Сначала пробует **LuckPerms** через рефлексию (без жёсткой зависимости в `build.gradle`) — работает "из коробки", если LuckPerms доступен в той же JVM (актуально для гибридных серверов Forge+Bukkit вроде Arclight/Mohist/Banner, где рядом с Forge крутится LuckPerms).
  2. Если LuckPerms не найден — пробует нативный `PermissionAPI` Forge (задел на будущее для чистых Forge permission-модов).
  3. Если ни один провайдер не подключён — падает обратно на простую проверку OP (уровень 2).

  Не найдена нода — игрок получает явное сообщение в чат `§cУ вас нет прав на этот набор`.

## Что можно добавить дальше

- **Лента выигрышей в CasesScreen** — сейчас показывается только на главном меню, можно продублировать сбоку и в разделе кейсов.
- **Подсветка/замок на кнопках китов**, к которым не хватает прав — сейчас это выясняется только в момент клика (сервер отвечает сообщением), клиент заранее не знает результат проверки LuckPerms.

- **Иконки в кнопках китов/варпов/квестов** — сейчас только кейсы показывают предмет-иконку, остальные разделы чисто текстовые.
- **Настоящая нижняя панель профиля с 3D-моделью игрока** (как в лаунчере) вместо плоской иконки головы.
- **История открытий кейсов** ("последние выигрыши всех игроков" — лента в углу главного меню, как в реальных кейс-системах, создаёт ощущение "живого" сервера).
- **Проверка прав через LuckPerms** для VIP-китов — сейчас поле `permission` в конфиге кита ни на что не влияет, это заглушка.
- **Полноценная интеграция вкладки "Привилегии"** с реальной покупкой валюты за реальные деньги (сейчас это статичная витрина без обработчика оплаты).
- **Звук/анимация при недостатке средств** — сейчас просто текстовое сообщение в чат.
- **Плавное появление кнопок меню** (fade/slide при открытии экрана) для более "живого" ощущения интерфейса.
- **Персистентность прогресса квестов и кулдаунов китов** между рестартами сервера (сейчас только баланс валюты сохраняется на диск, остальное — в памяти).
