# Установка на Mohist 1.20.1

## Что важно понимать

Mohist — гибрид Forge + Bukkit. Мод ставится в `mods/`, плагины остаются в `plugins/`.
Сам интерфейс рисуется **на клиенте**, поэтому сценариев два:

| Сценарий | Что видит игрок |
|---|---|
| Клиент с модом (ваш лаунчер) | полный хаб Aqua Lumen |
| Чистый ванильный клиент | хаб-сундук 3×9 с теми же разделами |

Сервер остаётся доступным для обоих: в `mods.toml` стоит `displayTest="IGNORE_ALL_VERSION"`, а сетевой канал принимает отсутствующие версии.

## Порядок установки

1. Java 17, Mohist для 1.20.1 (сборка на Forge 47.x).
2. Положите `aqualumen-forge-1.20.1-0.3.0-alpha.jar` в `mods/`.
3. Запустите сервер один раз → появятся `config/aqualumen-common.toml`.
4. Настройте `serverName`, `title` сезона, валютные objectives, список рангов.
5. В клиентскую сборку лаунчера добавьте тот же jar.

## Проверка

```text
/aqualumen status      # сколько хабов открыто
/hub                   # открыть интерфейс
```

Ожидаемо в логе: `[AquaLumen UI] hub interface ready (Forge 1.20.1, Mohist compatible)`.

## Частые грабли на Mohist

| Симптом | Причина и решение |
|---|---|
| `/hub` уже занят плагином | мод не регистрирует алиас, если команда занята; используйте `/aqualumen open` |
| Игроки без мода не видят красивый GUI | это ожидаемо: клиентские экраны невозможно рисовать с сервера; работает fallback |
| Лаги при многих открытых хабах | увеличьте `snapshotIntervalTicks` (40 → 100) |
| Спам кликами по кнопкам | `actionCooldownMs` уже ограничивает частоту; поднимите до 500–800 |
| Краш сервера от клиентских классов | весь клиентский код изолирован через `DistExecutor` и `Dist.CLIENT` |

## Интеграция с плагинами Bukkit

Мод не зависит от Bukkit API. Для связки с экономикой (Vault, CMI, свой плагин) есть два пути:

1. **Scoreboard** — плагин пишет баланс в objectives `coins` / `gems`, мод читает их сразу.
2. **Код** — замените метод `HubDataService#score` и обработчики `TODO bridge` в `HubActionHandler` на вызовы своего API.
