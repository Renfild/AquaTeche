# UI Style Guide — AquaLumen UI

Каркас и поведение повторяют Luminous UI (LoliLand). Отличие — только в палитре и акцентах.

## 1. Палитры

### Aqua Lumen (по умолчанию)

| Роль | HEX | Где |
|---|---|---|
| Canvas | `#070C12` | затемнение игры за панелью |
| Surface | `#0E151E` | основная панель (opacity 0.86) |
| Raised | `#16202C` | карточки, чипы |
| Border | `rgba(255,255,255,.09)` | границы 1px |
| Text | `#F2F7FA` | основной текст |
| Text dim | `#9DB2C4` | подписи |
| Accent | `#2FE0C0` | активное состояние, прогресс |
| Accent alt | `#3B9DFF` | второй цвет градиента |
| Gold | `#F5C25B` | премиум, валюта |
| Danger | `#FF6B6B` | смерти, ошибки |
| Success | `#4CD08A` | куплено, онлайн |

### Violet Lumen (референсная)

`#0B0713` • `#140E20` • `#1D1530` • accent `#B072FF` → `#FF6BC1` • gold `#FFC978`

### Midnight Rose (сезонная)

`#120A10` • `#1B0F18` • `#261722` • accent `#FF7A9C` → `#FFB27A`

Правило: один акцентный градиент на экран, золотой — только для премиума и валюты, красный/зелёный — только семантика.

## 3. Состояния

| Состояние | Визуал |
|---|---|
| Default | поверхность raised 75% + граница |
| Hover | фон 100% + внешнее свечение accent 6% × 3–4 слоя |
| Active | акцентная полоса 3px слева + фон accent 10% |
| Disabled | текст text dim, без градиента |
| Premium | градиент gold → accent alt, 16% заливка |

## 3.1 Движение

Все переходы кадронезависимые: `Anim.approach(current, target, speed, delta)`, где `delta = getDeltaFrameTime() / 20`. На 30 и 240 fps скорость одинаковая. Флаг `animations = false` заставляет каждую функцию `Anim` сразу возвращать конечное значение — reduced motion работает без ветвлений на местах вызова.

| Токен | Speed | ≈ время | Где |
|---|---|---|---|
| instant | 16 | ~110 мс | hover пунктов меню и кнопок |
| snap | 14 | ~130 мс | появление панели: фон, граница, свечение |
| soft | 9 | ~200 мс | въезд контента после смены вкладки |
| decay | 9–10 | ~180 мс | отдача после нажатия |
| toast | — | 3.2 с | тост с полосой остатка времени |

Кривые: `easeOutCubic` — появление, `easeOutBack` — бейджи и реветал кейса, `easeInOutCubic` — длинные сдвиги, `pulse(time, speed)` — дыхание свечения и пульс бейджа, `stagger(progress, i, n, 0.5)` — каскад плиток и карточек, `shimmer` — блик по закрытым наградам.

Запрещено: сдвиг макета под курсором больше 2 px, анимация ширины/высоты контейнеров, движение элементов вместе с их хитбоксом. Кнопки анимируют цвет, свечение и максимум 1 px нажатия, поэтому попадание курсора не уезжает. Контент вкладки едет внутри `enableScissor`, чтобы въезд не залезал на боковое меню.

## 3.2 Иконки

Иконки — настоящая векторная графика, а не пиксельные маски. Каждая описана штрихами SVG на сетке 24×24: толщина 2, круглые концы и стыки, никаких заливок. Источник лежит в `tools/icons.svg` — спрайт из 21 `<symbol>`, открывается любым векторным редактором.

Сборка: `tools/gen_assets.py` раскладывает символы в сетку 7×4 по 64 px, рендерит её headless-хромиумом с четырёхкратным суперсемплингом и печёт в атлас `assets/aqualumen/textures/gui/icons.png` (448×256). Атлас белый: в игре ячейка рисуется через `blit`, а цвет приходит из темы через `RenderSystem.setShaderColor`. Одна текстура обслуживает три палитры и любой accent из конфига, на весь хаб — один bind.

Размеры: 10 px — минимум (в `Icons.draw` это floor, ниже штрихи сливаются), 10–14 px — пункты меню и плитки статистики, 20 px — бейджи. Билинейная фильтрация включается один раз после первого blit, иначе ячейка 64 px мылит лестницей. При GUI-масштабе 2, который стоит у большинства игроков, иконка 10 px получает 20 реальных пикселей.

Порядок ячеек генератор читает из `enum Icon` в `Icons.java` и падает при любом расхождении, поэтому атлас не может разъехаться с кодом. Каталог для ревью — `docs/icon_sheet.png`.

Замечание по инструменту: headless-хромиум красит примерно на 88 CSS px меньше запрошенного окна, поэтому генератор всегда просит окно с запасом и обрезает кадр до точного размера. Без этого нижний ряд атласа уезжал в пустоту.

## 4. Информационная архитектура

```text
Шапка   : логотип • имя сервера │ онлайн • TPS • валюты • аватар
Меню    : Профиль • Магазин • Кейсы • Battle Pass • Топы • Настройки
Контент : hero-карточка → плитки статистики → списки/сетки
Подвал   : версия сборки │ подсказка клавиш │ пинг
```

Главное правило UX: переключение вкладки меняет только зону контента. Курсор никогда не теряет активный элемент.

## 5. Типографика

В игре — штатный шрифт Minecraft без тени (`drawString(..., false)`), три уровня: значение (text), подпись (text dim), акцент (accent). В веб-макетах — системный sans, 13/15/22 px.

## 6. Доступность

- Контраст текста к фону не ниже 4.5:1 (проверено для text и text dim на surface).
- Статус никогда не кодируется только цветом: рядом всегда текст или значок.
- Кликабельная высота не меньше 16 GUI-пикселей.
- Прозрачность панели регулируется (0.35–1.0) — для читаемости поверх яркого мира.

## Токены 0.3 — покупка, лента, состояния

Окно подтверждения: ширина 480 px, скрим `rgba(0,0,0,.52)` с размытием, карточка выезжает через `easeOutBack`. Длинное значение переносится под свою подпись, а не жмётся в правую колонку. `Enter` — подтвердить, `ESC` и «Отмена» — закрыть; пока окно открыто, ввод под ним заблокирован.

Лента кейса: ячейка 80 px, зазор 10 px, шаг 90 px. Прокрутка `cubic-bezier(.16,.84,.2,1)` за 4.2 с, по краям маска гасит ленту на 12%. Тикер стоит по центру и разорван посередине, чтобы не перечёркивать выигрыш. Выигрыш определяет сервер до старта анимации.

Редкость: обычный — `dim`, редкий — `accentAlt`, легендарный — `gold`. Цвет всегда дублируется подписью, а в арте карточки поддержан радиальным свечением 15–19%.

Замок значит «закрыто покупкой». То, что просто ещё не открыто по прогрессу, показывается затемнением 55% и шиммером — без замка.

Сетка карточек тянется на высоту панели: ряды равной высоты, цена и кнопка прижаты к низу карточки. Строки таблиц — один шаг, лишнее место уходит в зазоры, а не в высоту последней строки.

## Пустые состояния, ошибки и подсказки

Пустое состояние — это иконка 46 px в рамке, заголовок, одно предложение с причиной и одно действие. Фильтры, меню и шапка остаются на месте: пустая вкладка не должна выглядеть сломанной.

Текст объясняет причину и путь дальше, а не констатирует «нет данных»: «Ключей нет» рассказывает, где их берут, «Каталог пуст» — что фильтр можно сменить.

Ошибка связи не стирает данные. Последний снимок остаётся на экране под вуалью с возрастом данных, а всё, что может быть устаревшим — чипы шапки, бейджи меню, сезонная карточка — тускнеет одновременно. Зелёная точка online становится красной.

Подсказка: 11.5 px, появляется на 9 px ниже элемента, ширина по содержимому, без переносов. Она поясняет то, что уже видно, и никогда не прячет единственный способ узнать важное.

Кулдаун 350 мс не молчит: частые клики получают тост с полосой ожидания, иначе игрок считает интерфейс зависшим. Сами тосты живут выше подвала (94 px от низа) и не перекрывают подсказки клавиш.
