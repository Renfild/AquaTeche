AquaTech — как обновлять клиентскую сборку
==========================================
Лаунчер: dist\releases\AquaTechLauncher.exe  (сейчас v2.3.0)
Пак:     dist\AquaTech-Client  и  dist\releases\AquaTech-Client


────────────────────────────────────────
1. ТЫ (локально на своём ПК)
────────────────────────────────────────
1) Меняешь моды / kubejs / конфиги
   - из CurseForge-инстанса, или
   - из server\mods / server\kubejs и т.п.

2) Публикуешь пак (пересобирает AquaTech-Client + manifest.json по MD5):
   python C:\Users\xieto\Desktop\AquaTech\tools\publish_client_pack.py

3) Запускаешь свой лаунчер:
   dist\releases\AquaTechLauncher.exe
   → в логе: «Локальная сборка: ...\AquaTech-Client»
   → подтянет только новые/изменённые файлы по MD5


────────────────────────────────────────
2. ДРУЗЬЯ — онлайн-обновление (без zip)
────────────────────────────────────────
Нужен твой ПК онлайн + sync-сервер + тоннель Playit.

Каждый раз после правок сборки:
  A) python tools\publish_client_pack.py
  B) Запусти start_sync_server.bat  (раздаёт пак на порту 8080)
  C) В Playit.gg: TCP-тоннель → локальный порт 8080
  D) Скопируй публичный URL, например:
       http://katherine-hydro.tun.ply.gg:XXXX

У друзей в лаунчере:
  • поле «URL обновлений» = этот Playit URL
    (или файл update_url.txt рядом с exe — одна строка с URL)
  • кнопка «Обновить» — только синк
  • «Играть» — тоже синхронизирует, потом запускает игру

Качает только файлы с другим MD5. Sync-сервер и Playit должны быть запущены,
пока друзья обновляются / ставят сборку.


────────────────────────────────────────
3. ДРУЗЬЯ — без онлайн (разово)
────────────────────────────────────────
Скопировать им папку целиком:
  dist\releases\
    AquaTechLauncher.exe
    AquaTech-Client\   (mods, kubejs, config, manifest…)

Либо позже GitHub Release (если настроишь gh):
  gh release upload modpack-latest dist/AquaTech-Client/mods/*.jar --clobber
  и запушить dist/AquaTech-Client/manifest.json в репо.


────────────────────────────────────────
4. Быстрый чеклист «я поменял мод»
────────────────────────────────────────
[ ] Правки в CF / server
[ ] python tools\publish_client_pack.py
[ ] (для друзей) start_sync_server.bat + Playit :8080
[ ] Свой лаунчер → Играть / Обновить
[ ] Друзья → Обновить (URL обновлений заполнен)


Сервер игры (Minecraft) и sync-сервер обновлений — разные вещи:
  • игра: порт 25565 (уже через Playit)
  • обновления пака: порт 8080 (отдельный TCP в Playit)
