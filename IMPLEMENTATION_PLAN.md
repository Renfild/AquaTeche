## 🎯 Общий обзор архитектуры проекта

Проект **AquaTech** представляет собой высокотехнологичную океаническую сборку на базе **Minecraft 1.20.1 (Forge MDK 47.x + гибридный сервер Mohist)**. 

### Основная концепция сборки:
Игрок начинает выживание посреди бесконечного океана без традиционных подземных шахт. Вся добыча руд, металлов, органики и компонентов **Industrial Upgrade (IU)** строится на:
1. Многоуровневой системе рыбалки (**Resource Rods & StarCatcher**).
2. Автоматизации улова через **Авторыболов (`aquatech_ui:auto_fisher`)**, океанические фильтры и драги.
3. Сложной промышленной цепочке переработки в **Industrial Upgrade (IU)** и **Applied Energistics 2 (AE2)**.

  * `kubejs/startup_scripts/40_rod_durability.js`: `item.setMaxDamage(N)` — ранние 128, середина 192, поздние 256, топ 320.

#### 🔄 Как обновлять клиентскую сборку (чеклист)

**Ты (локально):**
1. Меняешь моды / kubejs / конфиги (CurseForge или `server/`).
2. `python C:\Users\xieto\Desktop\AquaTech\tools\publish_client_pack.py`  
   → пересобирает `dist/AquaTech-Client` + `manifest.json` (MD5).
3. Запускаешь `dist\releases\AquaTechLauncher.exe`  
   → в логе: «Локальная сборка: …\AquaTech-Client»  
   → качает/копирует только изменённые файлы.

**Друзья — онлайн (без zip):**
1. После правок снова `publish_client_pack.py`.
2. `start_sync_server.bat` (HTTP на порту **8080**, раздаёт `dist/AquaTech-Client`).
3. Playit.gg: отдельный **TCP → 8080** (игра 25565 — другой тоннель).
4. Друзьям в лаунчере поле **«URL обновлений»** = публичный Playit URL  
   (или `update_url.txt` рядом с exe).
5. Кнопка **«Обновить»** или **«Играть»** — синк по MD5.

**Друзья — разово без сети:** скопировать папку `dist\releases\` целиком  
(`AquaTechLauncher.exe` + `AquaTech-Client\`).

**Опционально позже (GitHub):**  
`gh release upload modpack-latest dist/AquaTech-Client/mods/*.jar --clobber`  
+ запушить `manifest.json` в репо.

### 1. Сезонная подача — спина проекта

Цель: каждый сезон = страница + баттл-пасс + конкурс + анонс, ритм 1 раз в 3–4 месяца. Сезон — это способ упаковать контент, который уже выходит, а не повод делать вайп.

#### 1.1 Шаблон страницы сезона (`docs/season-XX.html`)

Собирается из существующих компонентов портала (`.hero-card`, `.section-head-split`, `.tag`, `.bento-card`, `.news-grid-home`) — новых слоёв CSS не заводим, страница не должна ломать перф-бюджет.

| Блок | Содержание |
|---|---|
| Hero | «Сезон II · \<Название\>», обложка 1200×630, срок сезона, CTA (лаунчер + Discord) |
| Главное в сезоне | 4–6 карточек: тег, заголовок, 2–3 строки, картинка (≤300 КБ) или гиф (≤1.5 МБ) |
| Баттл-пасс сезона | уровни, free/premium дорожки, цена, способы получать XP (задания, улов, события) |
| Конкурс сезона | номинации по существующим топам (рыболовы / онлайн / монеты / репутация), призы, сроки |
| Экономика: что изменилось | таблица «было → стало» (кейсы, курс Кота, дропы) — игроки это читают первым |
| Дальше | 2–3 пункта следующего сезона (публичный роадмап = удержание) |
| Футер | архив прошлых сезонов |

Бюджет веса: ≤ 2.5 МБ на страницу (у Meta страницы весят десятки МБ — не повторяем).

#### 1.2 Архив и навигация

- `docs/updates.html` — индекс сезонов карточками с обложками.
- `docs/season-01.html` — ретроспективно оформить текущее «Покорение Океана», чтобы архив не начинался с пустоты.
- Навигация: `NAV_MORE` в `site.js` → пункт «Обновления»; ссылки с главной (секция «Обновления и ивенты») и из `news.html`.
- Анонс каждого сезона: запись через `/api/news` (админка), посты в Discord и Telegram (боты и привязка аккаунтов уже есть).

#### 1.3 Ритм и пайплайн сезона

| Неделя | Шаг |
|---|---|
| −8 | Фиксация темы и 3–5 фич сезона, список изменений экономики |

#### 1.4 Баттл-пасс как конфиг, а не код

Сейчас сезон зашит в код/БД (`HubSnapshot.Season(...)`). Предложение по образцу `cases.json` / `kits.json`:

```json
{
  "id": "season-2",
  "title": "Сезон II: <Название>",
  "endsAt": "2026-12-31T23:59:59Z",
  "xp": { "perQuest": 25, "perCatch": 3, "perEvent": 40 },
  "tiers": [
    { "level": 1, "xp": 0, "free": [{ "type": "coins", "amount": 500 }], "premium": [{ "type": "gems", "amount": 20 }] }
  ]
}
```

Плюсы: новый сезон без пересборки мода; правки награды без релиза. Premium согласовать с существующими ценами: ранги 99–1499 ₽, `costCoins` кейсов от 2500.

### 2. Мета-системы (быстрые победы)

1. **Пити кейсов** — в `cases.json` добавить `pity: { every: N, rewardId }`, в UI кейса строку «До гаранта: M открытий», на сервере счётчик на игрока. Закрывает главную претензию к рандому и повторяет их «систему гарантов».
2. **Активируемые бустеры** — предмет/кнопка в F4 → временный множитель (улов ×1.5/×2, удача, XP пасса). Источники: кейсы, награды пасса, события. Сейчас есть только событийный `eventBoost` в `FishShopConfig`.
3. **Конкурс сезона** — таблица выплат и рейтинговые очки по уже считающимся топам, автоматические итоги по расписанию, пост в Telegram/Discord.
4. **Страница «Что мы делаем против лагов»** — лимиты регионов, свои машины, клиентские оптимизации, перф-пасс портала (первая загрузка 982 → 574 КБ, повторная 159 КБ). Два часа работы, сильный сигнал доверия.

### 3. Именованный PvE (контентная фаза)

Минимум для ощущения «полноценного» сервера: 3 босса, 1 многоэтажный данж, 3 локации — с экономической ролью, а не декорацией.

- **Боссы**: Кракен (щупальца-стаи), Левиафан (фазы с волнами и водоворотами), Утопший адмирал (миньоны-скелеты). Спавн по событию или ключу, пропорциональные награды, уникальный дроп → материал для T13-апгрейдов и косметики.
- **Данж «Затонувший город»**: 3 этажа с нарастающей сложностью, ключи из кейсов и событий, босс в финале, лут-таблица в стиле `rods.html`.
- **Локации-арены**: Гидротермальные жерла, Коралловые рифы, Марианская впадина — варпы, собственные ресурсы, привязка к событиям.

### 4. Дроны-миньоны (расширение существующей архитектуры машин)

7 машин → 12 единиц + уровни: буй-сборщик, дрон-разведчик (сонар), ремонтный дрон, дрон-охранник, дрон-курьер. МЭ-слот для дрона и коллекция, как у Meta-миньонов, но на уже написанном каркасе `aquatech_machines`.

### 5. Порядок работ и критерии готовности

| Фаза | Содержание | Срок | Критерий готовности |
|---|---|---|---|

### 6. Чего у MetaLabs не копируем

- **Вайпы сезонов** — у них OneBlock вайповый по задумке; у нас персистентный прогресс, сезонность делаем через пасс и конкурсы.
- **Стены контента** — 300 картинок на страницу и сотни машин за сезон; у нас курируемая сборка (69 модов) и быстрый портал.
- **Дерево талантов** — выпилено решением владельца, возвращать не планируется.
