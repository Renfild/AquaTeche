# Chunky — предгенерация чанков (установлен 2026-08-25)

**Зачем:** плот-спавн и океан вокруг него не лагают у новых игроков — чанки уже сгенерированы.

## Настройка после первого запуска сервера (в консоль/чат от имени консоли):

```
chunky radius world 3000
chunky center world 0 0
chunky start world
```

Или точечно вокруг спавна (быстрее, рекомендую первым делом):
```
chunky center spawn
chunky radius spawn 1500
chunky start spawn
```

Статус прогресса: `chunky silent` (выкл спам), `chunky status`.

## Рекомендуемые области
- **spawn**: радиус 1000–1500 (плот-спавн + гавань)
- **world**: полный радиус 3000+ — запускать на ночь

## Важно
- Не запускать полную генерацию при игроках онлайн — жрёт CPU, TPS просядет.
- После завершения `chunky continue` больше не нужен: чанки сохранены в region.
- Конфиг мода лежит в config/chunky/ после первого запуска.
